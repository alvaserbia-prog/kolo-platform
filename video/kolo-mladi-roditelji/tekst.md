# KOLO video 22 — Mladi roditelji (Jovana, Nemanja i beba)

Stanje: **nacrt teksta (korak 1), čeka odobrenje vlasnika.** Scenario se piše posle odobrenja.

## Odluke vlasnika (04.10.2026)

- Video je o mladim roditeljima sa bebom: šta im KOLO donosi u životu i oko deteta. Mesto u redosledu: 22.
- Luk se delom uzima iz videa 6 (`kolo-domacice/`): problem iz kuće → najniža tačka → KOLO → oglas → razmena → povratak.
- Unutra moraju biti: **domaća zdrava hrana za bebu** (voće i povrće, neprskano), **čuvanje deteta**, a **Podrška majkama ide na kraj**.

## Pretpostavke koje čekaju potvrdu

- Bebu čuva **Milica** iz videa 6; odjek njene rečenice „opet ima za koga“.
- Kraj je **poziv** („Imaš malo dete? Pridruži se…“), ne pitanje gledaocu.

## Tekst za snimanje (nacrt)

Oznake: / kratka pauza · // duža pauza · `[ovako | ili ovako]` izbor

1. Jovana i Nemanja dobili su bebu. // Za tri meseca / beba je prerasla / sve što su joj kupili. //
2. Pre bebe / živeli su skromno, / ali bez brige. / Oboje rade, / stan je pod kirijom. //
3. `[Onda je sve postalo duplo. | Onda su troškovi porasli.]` / Pelene, / hrana, / lekar. / Jovana je na porodiljskom, / plata je manja. //
4. A bebi hoće da daju / samo najbolje. / Domaće voće i povrće, / neprskano. / Samo, / gde to da nađu u gradu? //
5. Babe i dede su daleko. / Kad beba ne spava, / nema ko da je pričuva / ni sat vremena. //
6. Jedne večeri / Nemanja je sabrao račune / i rekao: / ovako ne ide. //
7. U KOLU / ono što je jednoj porodici višak, / drugoj baš treba. //
8. Jovana je na KOLU objavila oglas: / garderoba za bebe / do tri meseca. / Došla je komšinica / koja čeka bebu. / I prepisala joj POENE, / onoliko koliko su se dogovorile. //
9. Tim POENIMA / dobili su kolica / od porodice / čija su deca porasla. / A Nemanja je jednom komšiji / sklopio orman / i za to dobio POENE. //
10. Sa salaša kod Sombora / stižu im jabuke, / šargarepa / i bundeva. / Neprskane. // Od njih Jovana pravi kašice. //
11. A subotom ujutru / bebu čuva Milica / iz susedne ulice. // Jovana i Nemanja / prvi put posle tri meseca / piju kafu na miru. // `[A Milica kaže / da opet ima za koga. // | —]`
12. Dinari koje bi dali / za kolica i garderobu / ostali su im / za ono što u KOLU ne mogu da nađu. //
13. I još nešto. / Dok je beba mala, / Jovani se svakog dana / upisuju POENI. / Zato što je mama. `[| / Kad su to potvrdili / ljudi koji je znaju.]` //
14. Imaš malo dete? / Pridruži se besplatno / na ekolo.rs.

## Pravila koja tekst i slika moraju da poštuju

- Podrška majkama: ne piše se da Fondacija „dodeljuje“ (stoji „upisuju se“) i ne navodi se iznos
  (Pravilnik o programima podrške, čl. 4 i 7–9).
- Uz POEN nema reči kupi, prodaj, plati, zaradi, cena; „kupili“ ide samo uz dinare (sc. 1).
- POEN se upisuje kad je stvar u rukama; ušteda se iskazuje kao dinari koji su ostali (sc. 12).
- „Neprskano“ je ono što je stiglo sa salaša, ne tvrdnja Fondacije o kvalitetu.
- Nove pelene i adaptirano mleko se ne obećavaju kroz KOLO.
- Slika (sc. 8–13) može da pokazuje kako pored Jovaninog imena raste zapis, red po red; POEN samo kao zapis.
