## b) Tekst za snimanje

Oznake: / kratka pauza · // duža pauza

1. Milica je celog života pravila zimnicu. // A onda je prvi put / bacila teglu ajvara. //
2. Milica to voli / i zna. / Vrsna domaćica. // Njena porodica uživala je / u najboljim delicijama: / ajvar, / turšija, / pekmez, / sokovi. / Po bakinom receptu, / bez konzervansa. //
3. Onda su deca otišla svojim putem. / Velika porodica / spala je na dva slova. //
4. Još nekoliko godina je pravila, / misleći da će je dati / deci i unucima. / Ali oni su dolazili retko. / Tegle su stajale. // I Milica je počela da baca. //
5. Zato je jedne jeseni rekla: / dosta. // Više ne pravim. //
6. U KOLU / zimnica ne mora da propadne. / Tu se nađe neko / ko bi se rado podsetio / ukusa svog detinjstva. //
7. Milica je na KOLU objavila oglas. / Komšija iz susedne ulice / došao je po tri tegle. / I prepisao joj POENE, / onoliko koliko su se dogovorili. //
8. Tim POENIMA / Milica sada dobija pomoć u kući. / Neko joj očisti oluke. / Neko pokosi travu. //
9. Milica ponovo pravi zimnicu. // Jer opet ima za koga. //
10. Znaš nešto da napraviš? / Neko u tvom kraju / baš to traži. // Pridruži se besplatno / na ekolo.rs.

## Pravila koja slika mora da poštuje

- POEN se nikad ne crta kao novčić ni novčanica — samo kao zapis („Komšija → Milica · N POENA“).
  Iznos se ne ispisuje kao preračun u dinare.
- Bez reči kupi, prodaj, plati, zaradi, cena — ni u titlu ni u natpisu na slici (oglas nema „cenu“).
- Pomoć u kući (sc. 8) je nova razmena preko POENA, ne „usluga Fondacije“.
